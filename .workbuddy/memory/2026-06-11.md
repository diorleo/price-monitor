# 2026-06-11 工作日志

## 修复：Render 部署的渠道持久化 + CSP + Run Crawl

### 问题
1. 网站点 Run Crawl 没反应
2. 加的渠道/产品刷新后消失
3. 控制台报 CSP 错误（Content Security Policy blocks eval）

### 修复内容
- **`backend/app.py`** — 添加 `@app.after_request` 覆盖 CSP 头，允许 `unsafe-eval`（Chart.js 需要）；`static_folder` 改用绝对路径
- **`webapp/index.html`** — 全面修改：
  - `renderChannels()`: API 模式下也合并 localStorage 缓存的渠道，防 Render 重启丢失
  - `saveChannel()`: API 保存成功后同步写 localStorage
  - `deleteChannel()`: API 删除后同步从 localStorage 移除
  - `renderProductTable()`: 同上合并逻辑
  - `saveProduct()`: 同上写 localStorage
  - `deleteProduct()`: 同上删 localStorage
- **`index.html`**（根目录）— 同步 webapp/index.html 到根目录，供 GitHub Pages

### 根因分析
- Render 免费版每次重启抹掉 SQLite 数据库 → 用户渠道/产品丢失
- Render 默认注入严格 CSP → Chart.js 的 eval 被拦
- 前端在 API 模式下只读写后端，不做 localStorage 缓存 → 无灾备
